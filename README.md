# Hangman Game

A classic browser-based Hangman game where you guess the hidden word one letter at a time! This project is a fun, interactive implementation using HTML, CSS, and JavaScript, and is playable instantly via [GitHub Pages](https://sruthivellore.github.io/Hangman).

---

## 🎮 How To Play

- **Objective:** Guess the hidden word by selecting letters from the alphabet.
- **Gameplay:**
  - Each incorrect guess draws a new part of the hangman.
  - You have a limited number of incorrect guesses before the game ends.
  - Correct guesses reveal the letter in the word.
  - Win by revealing all the letters before the hangman is fully drawn.
  - Lose if the hangman drawing is completed before you guess the word.

---

## ✨ Features

- **Interactive UI:** Click or tap on letters to make your guesses.
- **Visual Feedback:** The hangman drawing updates with each incorrect guess.
- **Word Display:** Correctly guessed letters are revealed in their positions.
- **Game Over Handling:** The game announces a win or loss and can be restarted easily.
- **Responsive Design:** Play comfortably on desktop or mobile browsers.
- **No Dependencies:** Runs entirely in your browser-no installation required.
